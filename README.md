# DayDreamTeam (DDT)

Photography & visual art portfolio built with Next.js App Router.

## Quick Start

From the `ddt` folder:

```bash
nvm use
npm install
npm run dev
```

Open `http://localhost:3000`.

Use Node 20.9 or newer. Next 16 will fail to build on older Node versions.

## Scripts

- `npm run dev` – start Next.js dev server
- `npm run build` – production build
- `npm run start` – run production server
- `npm run lint` – run ESLint
- `npm run clean` – removes `.next`, `.turbo`, and `node_modules/.cache`

## Environment Variables

Create `.env.local` in the `ddt` folder:

```bash
# Required for Vercel Blob reads
BLOB_READ_WRITE_TOKEN=

# Optional (recommended for correct absolute URLs in sitemap/metadata)
NEXT_PUBLIC_SITE_URL=https://your-domain.com

# Optional (recommended): refresh project data on demand
REVALIDATE_SECRET=some-long-random-string
```

Notes:
- `BLOB_READ_WRITE_TOKEN` is the Vercel Blob token used by `lib/blob.ts`.
- `NEXT_PUBLIC_SITE_URL` is used to generate absolute URLs for SEO metadata routes.

## SEO (Next.js Standards)

This app uses Next.js metadata routes:

- `GET /sitemap.xml` (generated by `app/sitemap.ts`)
- `GET /robots.txt` (generated by `app/robots.ts`)

Global SEO tags (Open Graph / Twitter / keywords) live in `app/layout.tsx`.

## Updating Images (Vercel Blob)

This app uses Vercel Blob as its image store. Each project folder is a prefix under `photos/`, and the helpers in `lib/blob.ts` list and read its contents.

### Recommended setup

1) Create a Blob store in the Vercel dashboard
2) Add `BLOB_READ_WRITE_TOKEN` to the Vercel project environment variables
3) Upload files under paths such as `photos/project-name/`
4) Keep a metadata file alongside the images

### Revalidation

Keep `REVALIDATE_SECRET` in place to refresh project data after uploads or reordering.

### Project Metadata

Project data comes from a metadata file inside each Blob project folder.

Supported files:
- `project.json`
- `metadata.json`
- `project.txt`
- `metadata.txt`

Example `project.json`:

```json
{
  "id": 12,
  "title": "North Harbor",
  "year": "2025",
  "categories": ["COLOUR", "PORTRAIT", "STILL LIFE"],
  "tags": ["coastal", "summer", "beach"],
  "description": "A series exploring morning light on the harbor edge."
}
```

The app reads the metadata file and ignores folder naming as the source of truth. If a project folder has no metadata file, it is skipped.

### Project Descriptions

If you keep a `description.txt` file alongside a project's images, it populates `project.text` as a plain-text fallback.
